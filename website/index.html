Why ButtonsCLI

Command buttons

      
Stop retyping the same ten commands

      
A top bar and a side dock hold your commands: SSH logins, docker compose shells, deploy steps, log tails. Click one and it types into the focused pane.

      
    
        
  • Choose per button whether it presses Enter or waits for you to review.
    • 
        
  • Separate collections for everyday commands and SSH hosts.
    • 
        
  • Keyboard first when you want it: F6 moves between the dock and the terminal.
    • 
      

    

    
  


  

    

      
AI practice terminal

      
A safe Linux box that does not exist

      
Open a simulated terminal and an AI model plays the machine. Type ls -a, htop, install packages, write a script in nano and run it. Nothing touches your computer.

      
It is a good way to learn the shell, demo a tool, or practice a risky command first. You write the system prompt in plain English and use any model you have a key for.

    

    
  


  

    

      

        
Real screenshots

        
Seven shells, one window

      

      
Every pane runs a real shell with its own theme and background: a galaxy here, stained glass there, a VHS tape in the corner. Right-click any pane to change its theme or font on the spot.

    

    
    

      
      
    

    
  


  

    

      

        
GPU shader backgrounds

        
34 living backgrounds

      

      
Each pane can run its own animated background behind the text, rendered on the GPU. Calm mode freezes motion, strength stays capped so text stays readable, and you can write your own in a small built-in editor or ask AI to write one.

    

    

      
      
      
      
      
      
      
      
      
      
      
      
    

  


  

    

      
Themes and fonts

      
550+ themes, one per pane if you like

      
Browse a searchable library, apply a theme to everything or to one terminal, or describe a look and let AI generate a palette that keeps text readable. Fonts, gradients and effects can each come from a different theme.

      
26 font faces ship with the app and work offline.

    

    

      
      
    

  


  

    

      
For AI coding agents

      
Let your agent drive a terminal you can watch

      
ButtonsCLI runs a local, token-protected control service. Claude Code, Codex or any MCP client can open tabs, type, run commands, wait for output and read the screen, while you watch every pane live.

      
    
        
  • CLI helper and an optional MCP server, copied with one click.
    • 
        
  • Listens on 127.0.0.1 only, with a fresh token each run.
    • 
        
  • Built-in AI Help explains output and suggests commands you review before they run.
    • 
      

    

    
  


  

    

      
Shader editor

      
Write your own background

      
Type a one-line color expression, see it compile live, and drag sliders you attach to it. Stuck? Describe the look, or press Fix with AI, and the app asks your model for a version that compiles.

    

    
  


  

    

      
Spec sheet

      
Under the hood

    

    

      
Terminal core
Alacritty's terminal engine with a real PTY per pane

      
UI
Rust, egui and wgpu. No browser runtime, no Electron

      
Startup
Window on screen in 0.47 s (release build, Windows 11)

      
Panes
Columns, rows or grid; panes reflow as you add them

      
Themes
Over 550 built in, plus your own and AI-generated ones

      
Backgrounds
34 GPU shader presets, including VHS and CRT static, and a custom shader editor

      
AI providers
OpenAI, Anthropic, OpenRouter, Mistral, Groq, NVIDIA NIM or any OpenAI-compatible endpoint; keys stay in your OS credential store

      
Platforms
Windows today; Linux builds in CI
