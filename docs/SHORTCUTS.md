# Keyboard shortcuts

Open **Settings → Shortcuts** to change the app's shortcuts. Select **Record**,
press a key combination, and the app saves it to the active profile. Use
**Clear** to remove one binding or **Restore defaults** to return to the
original native bindings. Press Escape while recording to cancel.

The defaults are:

| Action | Default |
| --- | --- |
| New tab | `Primary+Shift+T` |
| Close tab | `Primary+Shift+W` |
| Reopen tab | `Primary+Shift+U` |
| Copy selection | `Primary+Shift+C` |
| Paste | `Primary+Shift+V` |
| Open Settings | `Primary+Shift+,` |
| Quit | `Primary+Shift+Q` |

`Primary` means Ctrl on Windows and Linux, and Command on macOS. You can use
letters, digits, F1–F12, Page Up/Down, Home, End, Insert, Delete, Tab, Enter,
Escape, Space, comma, plus, and minus. A shortcut needs Primary, Ctrl, or Alt
so ordinary typing does not trigger app commands. Duplicate combinations are
rejected. Ctrl+C always stays reserved for terminal interrupt. Primary+C
without Shift is also blocked so the same setting stays safe on Windows and
Linux; use the default `Primary+Shift+C` for copy instead.

The original app's custom shortcut settings remain preserved in the imported
compatibility data but are not activated. Native currently exposes the seven
actions above; other original actions depend on features that have not been
ported yet.
