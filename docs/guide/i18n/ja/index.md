# ButtonsCLI ガイド

ButtonsCLI は、キーの組み合わせを覚えるよりクリックしたい人のための
ネイティブターミナルです。長いコマンドはボタンに置き、ペインは自動で並び、
ペインごとに独自のテーマ、フォント、アニメーションするシェーダー背景を
設定できます。シェーダーは AI に書いてもらうこともできます。

## 設計の考え方

- **ペインは「位置」です。** Pane 1、Pane 2… は画面上の場所です。ルック、
  バンドル、「Edit for」はすべて位置を指すので、バンドルはどのターミナルにも
  使えます。
- **作業を止めません。** ペインを切り替えても設定を閉じても、保存を求められる
  ことはありません。未保存の変更は番号付きのコピーとして保存されます。
- **文字は読みやすいまま。** シェーダーは文字の*後ろ*に描かれます。Strength
  スライダーで明るさを決め、ターミナルの文字がゆがむことはありません。
- **AI は任意です。** AI なしでもすべて動きます。使うときはプロバイダーと
  モデルを自分で選び、キーは OS の資格情報ストアに保存されます。
