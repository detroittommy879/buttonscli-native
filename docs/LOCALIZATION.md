# Language settings

Open **Settings → Language & Region** to follow the operating system language or
choose a language for ButtonsCLI. The first launch on a new install offers the
same choice. Existing native settings keep their current language and do not
show the first-run prompt again.

The bundled source catalog includes 21 languages: English, Arabic, Chinese
(Simplified and Traditional), Danish, Dutch, Finnish, French, German, Hindi,
Italian, Japanese, Korean, Norwegian, Polish, Portuguese (Brazil), Russian,
Spanish, Swedish, Turkish, and Ukrainian. Translated labels update in the main
window, app menus, detached Settings, and AI Help. Imported original profiles
carry their system/manual language choice and manual locale into the native
settings.

Text without a matching source-catalog entry uses English. Bundled fallback
fonts include Arabic, Devanagari, Chinese and Japanese samples, plus all 11,172
modern Hangul syllables. Full right-to-left layout and actual glyph rendering
still need hands-on review. Keyboard focus, long translated labels, RTL, and
IME behavior still need hands-on Windows review.
