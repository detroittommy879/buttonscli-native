    How it works

    1. 1

      Click Agent Inst.

      The status bar button copies instructions for this running app: where its connection file is and which helper to call. The token stays in the file, not in what you paste.

    2. 2

      Paste into your agent

      Claude Code, Codex, Antigravity, or anything else that can run a command line tool or use an MCP server. No Node, Python or other runtime is needed.

    3. 3

      Watch the panes

      The agent opens tabs, arranges them, types commands and reads the output back. Each pane is a normal terminal: click it and type, or press Ctrl+C yourself.

    From a shell

    buttonsclictl ships next to the app. An agent that can run commands can use it directly.

    # lay out four named tabs in a grid
$ buttonsclictl open-layout --layout grid \
    --name server --name tests --name git --name logs
# run a command and wait for its output to settle
$ buttonsclictl run --tab tests "npm test"
# read back what the pane shows
$ buttonsclictl read --tab tests --lines 40
# stop the dev server
$ buttonsclictl key ctrl+c --tab server

    Or over MCP

    The same helper is a stdio MCP server. Agent Inst. copies an entry like this with your real paths.

    {
  "mcpServers": {
    "buttonscli-native": {
      "command": "C:/Program Files/ButtonsCLI/buttonsclictl.exe",
      "args": ["mcp"],
      "env": { "BUTTONSCLI_CONTROL_INFO_PATH":
               "C:/Users/you/.buttonscli-native/control" }
    }
  }
}

    The 14 tools

    read-only Look

    • status is the app running and reachable
    • tabs list tabs, shown and hidden
    • read recent output from a tab
    • wait_for_text until a marker appears
    • wait_for_quiet until output stops changing
    • presets your saved command buttons
    • help tool list and tab selector rules

    layout Arrange

    • create_tab a new named terminal
    • rename_tab so tabs say what they are for
    • open_layout named tabs side by side, stacked or in a grid

    sends input Act

    • run type a command, then wait for text or quiet
    • send text or a long paste, with or without Enter
    • key Ctrl+C, Ctrl+D, Ctrl+Z, Enter, Tab, Escape
    • preset_run press one of your command buttons

    Tools carry read-only and destructive labels, so an MCP client can ask you before the ones that send input.

    Good to know

    • Local only. The control service listens on 127.0.0.1 with a random port and a new token each time the app starts. It refuses requests that come from a web page.
    • Real shells. What the agent sends is typed into a real terminal. Connect only clients you trust.
    • Long jobs keep running. A dev server or log tail lives in its tab, not inside one agent tool call.
    • No exit codes. run reports when output went quiet or matched your text. It does not say whether the command succeeded; the agent reads the output for that.
