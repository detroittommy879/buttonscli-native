# Font attribution

`NotoSansKR-Subset.ttf` is a subset of Noto Sans CJK KR Regular (Version
2.004). Its source is `Sans/Variable/TTF/Subset/NotoSansKR-VF.ttf` in
[`notofonts/noto-cjk`](https://github.com/notofonts/noto-cjk), revision
`f8d157532fbfaeda587e826d4cd5b21a49186f7c`. The variable font was instantiated
at weight 400 and subsetted to the Hangul Jamo and Hangul syllable Unicode
ranges so all 11,172 modern Hangul syllables are available offline.

The font is distributed under the SIL Open Font License 1.1; the complete
license is included as `OFL-Noto-Sans-CJK.txt`. The source copyright notice
and font name metadata are retained in the subset.
